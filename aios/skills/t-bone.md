# T-Bone — Medical Affairs Impact Evaluator
_Skill v1.0 · Owner: @franchise-architect + @t-bone · Last run: never_

> **"Activity is not impact."** — Humberto Fonseca, MD
>
> Stop counting meetings held, touchpoints logged, decks submitted, satisfaction scores.
> Start measuring: Did it change strategy? Did it shift the narrative? Did it get prioritised?

---

## What this Skill does

Takes any Medical Affairs initiative, activity, or deliverable and:
1. **Strips the vanity metrics** — exposes if you're tracking activity instead of impact
2. **Maps to the Impact Matrix** — positions it on the AI transformation 2×2
3. **Generates impact-focused KPIs** — what you should actually measure
4. **Recommends the AI lever** — which AI use case accelerates this initiative

---

## THE IMPACT LENS

### What MA Measures (Activity — WRONG)
| Metric | Why it's hollow |
|---|---|
| Meetings held | Volume ≠ influence |
| Touchpoints logged | CRM entries ≠ strategic conversations |
| Decks submitted | Output ≠ outcome |
| Satisfaction scores | Politeness ≠ behaviour change |

### What MA Should Measure (Impact — RIGHT)
| Impact question | What it actually tests |
|---|---|
| Did the advisory board input change the label strategy? | Scientific influence → regulatory outcome |
| Did the field insight shift the commercial narrative? | Field intelligence → commercial pivot |
| Did the data gap we flagged get prioritised in the publication plan? | Evidence strategy → portfolio defence |

### The T-Bone Test (run for every initiative)
For any MA activity, answer these three questions:
```
1. STRATEGY SHIFT:  Did this change a decision at the brand/portfolio/regional level?
                    [Yes → Impact] [No → Activity theatre]

2. NARRATIVE SHIFT:  Did this shift how anyone outside MA talks about our science?
                     [Yes → Impact] [No → Internal echo chamber]

3. PRIORITY SHIFT:   Did this move something up (or kill something) on a resource plan?
                     [Yes → Impact] [No → Busywork]
```
**Scoring**: 3/3 = Ship it. 2/3 = Strengthen the weak link. 1/3 = Rethink. 0/3 = Kill it.

## EXAMPLES

### Example 1: Advisory Board
**Input**: "Running an adboard on Rekovelle PGT data with 8 KOLs"
```
T-BONE TEST:
  Strategy shift?   → Will adboard output feed into label extension filing? If yes = Impact.
  Narrative shift?   → Will KOL quotes reshape the IVF community conversation? If yes = Impact.
  Priority shift?    → Will gaps identified reprioritise the publication plan? If yes = Impact.

MATRIX:  External × Incremental (current) → could upgrade to External × Transformational
         if we add AI-personalized pre-reads and post-event insight extraction.

IMPACT KPIs:
  1. # of adboard recommendations adopted into brand strategy (not # of meetings)
  2. # of KOLs who independently reference our data post-event (not satisfaction score)
  3. # of evidence gaps that entered the publication pipeline (not decks submitted)

AI LEVER: KOL Insights Generation + Personalized KOL Engagements at scale
```

### Example 2: Slide Deck
**Input**: "Building a Menopur RWE slide kit for field team"
```
T-BONE TEST:
  Strategy shift?   → Does this deck arm the field team with a new competitive argument? 
  Narrative shift?   → Will HCPs change their prescribing conversation after seeing this?
  Priority shift?    → Does this address the #1 field-identified barrier?

MATRIX:  Internal × Incremental (content creation) → automate via @toolsmith

IMPACT KPIs:
  1. # of HCPs who shift Menopur higher in their protocol after exposure (not decks delivered)
  2. Field team confidence score on RWE narrative (not satisfaction with the deck)
  3. Competitive win rate in accounts where deck was used vs. not

AI LEVER: Content Creation (mail→manuscript) + MedComm Review System
```

## INTEGRATION WITH AIOS

- **Pre-flight**: Run T-Bone before starting any MA initiative to validate it's worth doing
- **Mid-flight**: Re-run at midpoint to check if you're still tracking impact, not activity
- **Post-flight**: Run final T-Bone to generate the impact report (not the activity report)
- **Council routing**: T-Bone output feeds directly into which specialist(s) to invoke
- **Ledger**: T-Bone verdict feeds into `aios/ledger/` for cost/payoff tracking
