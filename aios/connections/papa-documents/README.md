The Gmail MCP cannot download attachments directly. To get the actual files:
1. **Google Takeout** (takeout.google.com) → export Gmail → filter by Papa's emails
2. **Or** open each email in Gmail and download manually
3. Rename using the manifest in each year folder and drop into the right folder
